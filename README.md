# 节流记账本 · UI 作品集

微信小程序「节流记账本」的高保真矢量 UI 还原稿，用于产品设计作品集展示。

**在线预览**：https://yqw43434-alt.github.io/jieliu-portfolio/

## 内容

| 路径 | 说明 |
| --- | --- |
| `index.html` | 单文件离线作品集：11 张 SVG 全部内联，点图放大，每张可单独下载源文件；也可下载后双击本地打开 |
| `assets/svg/` | 11 张矢量源文件，可直接导入 Figma / 墨刀 |
| `assets/png/` | 11 张 PNG 预览（8 屏为 @2x，750 × 1624） |
| `节流记账本-UI素材包.zip` | 上述内容的打包下载 |

## 画面清单

8 屏核心界面：首页、记一笔、总明细、周期总结、设置、存款账户、借出借入、周期结算。
3 张说明板：8 屏总览与项目定位、设计规范（色板 / 字阶 / 圆角 / 组件）、核心流程与设计决策。

## 规格

- 单屏画板 375 × 812 pt，对应小程序 750 rpx 设计稿的 1/2
- 主色 `#0F766E`、页面底 `#F4F5F7`、主文字 `#111827`
- 字体 `PingFang SC`，已内置 Windows / Android 中文黑体回退
- 全部为 `rect / text / line / circle / g` 矢量元素，无位图、无滤镜、无外链资源
- 文字保留为可编辑文本层，卡片、按钮、色点、进度条均为独立矩形

## 导入设计工具

- **Figma**：`File → Import`，或把 SVG 直接拖进画布；可一次多选，各自生成独立 Frame。
- **墨刀设计**：文件浏览器「导入文件」选 SVG，或直接拖入编辑器画布；导入后可改填充、描边与锚点。

## 说明

画面内的金额、日期、账户名均为**演示样例数据**。产品逻辑与文案按小程序线上版本还原，界面元素为矢量重绘，非截图。
